# VibeWave website

Одностраничный сайт приложения [VibeWave](https://github.com/Slipcast-dev/VibeWave) в стиле Windows 95.

Сайт доступен по адресу https://slipcast-dev.github.io/vibewave-website/.

## Устройство

- `index.html` — разметка, русские и английские тексты, выбор языка и галерея.
- `style.css` — адаптивная вёрстка и оформление.
- `assets/` — официальные скриншоты приложения.
- `preview.png` и `preview-en.png` — превью обеих языковых версий.
- `.nojekyll` — публикация готовых статических файлов без обработки Jekyll.

Зависимости и сборка не требуются. При первом открытии выбирается поддерживаемый язык браузера. Ручной выбор сохраняется в localStorage, если браузер разрешает его использование.

## Локальный запуск

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/.

## Публикация

GitHub Pages публикует корень ветки `main`. После изменения файлов выполните:

```sh
git add index.html style.css assets
git commit -m "Update website"
git push
```

Статус публикации доступен в Settings → Pages и Actions репозитория.

## Обновление версии приложения

Сверьте опубликованный релиз VibeWave. Обновите ссылку на DMG, номер версии и описания возможностей на обоих языках в `index.html`. Скриншоты берутся из `docs/assets/` репозитория приложения. После изменения оформления обновите превью.

Исходные музыкальные файлы на сайт не загружаются.
